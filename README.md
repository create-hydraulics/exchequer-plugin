## Issue Submission Guidelines

To ensure rapid resolution times, all technical inquiries must utilize the formal issue templates provided in the tracking section. 

1. **Verify Your Environment:** Ensure your server environment matches supported platforms (Paper, Purpur, or Folia).
2. **Isolate Configuration Variables:** Check that calculation discrepancies are not caused by conflicting third-party integration placeholders or database replication lags.
3. **Provide Raw Traces:** Include clean, unedited stack traces or diagnostic exception dumps generated within `/plugins/Exchequer/logs/` or the console itself.
